# Phase 4 Implementation Plan — «i+1 Mini-Stories» & «Read & Retell»

> **Status: ✅ COMPLETE** — all 6 tasks done, 160/160 tests green, README updated.
> Sub-skill: superpowers:executing-plans (TDD inline execution).
> Spec: `SPEC.md` §15 Phase 4, `CURRICULUM.md` §9.

**Goal:** Add the `/story` command with adaptive i+1 mini-stories (100–150 words, 85–90% comprehensible), Smart Vocabulary Recycling (from learner's `srs_cards` and `corrections`), comprehension check (2 questions), and a voice retell challenge with Whisper transcription and target chunk validation.

---

### Task 1: Prompt & Service Core — `english_tutor/services/stories.py`
- Prompt generation with CEFR constraints (A2, B1, B2) + injection of recycled words from `srs_cards`/`corrections`.
- JSON schema:
  ```json
  {
    "title": "str",
    "text_en": "str (100-150 words with **bold** target chunks)",
    "glossary": [{"en": "str", "ru": "str"}],
    "comprehension_questions": [
      {
        "q": "str",
        "options": ["1. option A", "2. option B"],
        "answer": "1",
        "hint_ru": "str"
      }
    ],
    "retell_prompt": "str",
    "target_chunk": "str"
  }
  ```
- Validation `parse_story(raw: dict)` with strict type & length checking.
- `format_story(story: dict) -> str` with markdown text, glossary, and instruction for comprehension questions.
- Tests in `tests/test_stories.py`.

### Task 2: Smart Vocabulary Recycling Helper
- Helper `get_recycling_words(conn, student_id, limit=3)`:
  - Fetches up to 3 words from due/active `srs_cards` or recent `corrections`.
- Integrate into `generate_story_prompt(level, topic, recycling_words)`.
- Tests in `tests/test_stories.py`.

### Task 3: Stories SQLite Storage & Cache — `english_tutor/db.py`
- Table `stories` for generated stories (cached per student or level).
- Table `story_progress` (student_id, story_id, questions_score, retell_transcript, completed_at).
- Helper methods: `save_story`, `get_story`, `record_story_progress`.
- Tests in `tests/test_db.py` or `tests/test_stories.py`.

### Task 4: Retell Evaluator — `english_tutor/services/stories.py`
- `evaluate_retell(target_chunk: str, transcript: str) -> dict`:
  - Normalizes transcript and checks if `target_chunk` (or key parts) was used.
  - Generates encouraging feedback in Russian.
- Tests in `tests/test_stories.py`.

### Task 5: Telegram Handler `/story` & FSM — `english_tutor/handlers/stories.py`
- FSM: `StorySession.answering_questions`, `StorySession.waiting_retell`.
- `/story` triggers story generation (or next story) with recycling words.
- Answers 2 comprehension questions (choice 1 or 2).
- Prompts for Retell voice message (`🎤 Перескажи своими словами...`).
- Transcribes with Whisper, evaluates target chunk usage, stores progress, adds glossary chunks to SRS deck (`srs.ensure_card`).
- Register router in `english_tutor/bot.py`.
- Tests in `tests/test_stories_flow.py`.

### Task 6: Verification & Close-out

- Run full test suite (`uv run pytest`) and linter (`uv run ruff check .`).
- Commit and verify.
