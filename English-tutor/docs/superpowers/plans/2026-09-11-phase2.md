# Phase 2 Implementation Plan — Corrections, SRS, Reminders

> **Status: ✅ COMPLETE (2026-09-11)** — all 6 tasks done; 135 tests green, ruff clean.
> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, owner preference).
> Steps use checkbox syntax. Spec: `SPEC.md` §7, §10, §11, §15, §21 (items 11–12).

**Goal:** corrected conversation practice (JSON corrections → stored → auto-SRS), anki-style review flow, and twice-daily reminders — plus lesson_progress (K1) and ruff.

**Architecture:** all learner-facing state stays in SQLite; LLM calls via existing `chat_json_async`; chat/review flows follow the existing handler patterns (FSM thin, logic in services, `limits` guards on every LLM call).

**Tech Stack:** unchanged (aiogram 3, groq, sqlite3, pytest).

---

### Task 1: SRS engine — `english_tutor/services/srs.py`
- `INTERVALS = [1, 3, 7, 14, 30]`, `DEFAULT_BATCH = 10`
- `ensure_card(conn, tg_id, word_en, word_ru)` — INSERT OR IGNORE, due tomorrow
- `due_cards(conn, tg_id, limit)` — due_date <= today, ordered
- `get_card(conn, card_id)`
- `answer_card(conn, card_id, correct)` — up one step (capped) / reset to 1d
- `format_question(card)` RU→EN, `format_feedback(card, correct)`
- Tests (`tests/test_srs.py`): ladder 1→3→7→14→30, fail resets, dedup, due filter.

### Task 2: `/review` flow — `handlers/review.py` (+ lesson vocab auto-add)
- `Review.active` FSM; RU→EN per card; ✅/❌ feedback; end summary; /cancel works
- Auto-collection: on lesson completion every `vocab` item enters the deck
- `record_progress` (K1): lesson completion writes `lesson_progress(student, lesson_id, 'completed', score)`; `lessons.find_lesson_id` helper; FSM carries kind/level/topic + correct-counter
- Tests: review cycle, vocab auto-add, progress row written

### Task 3: Chat corrections — `services/chat.py` + `handlers/chat.py`
- `chat_system_prompt(level)`: one Groq call → `{"reply", "corrections": [{wrong, right, hint_ru}]}`
- `parse_chat(raw)` strict validation; `format_chat_answer(data)` → reply + «📝 Исправления:» / «(ошибок нет 👍)»
- `/chat` → `Chat.active`: 2–3 spine-topic suggestions, any topic allowed, text + voice answers
- Guards: `check_text`/`check_voice`/`can_use_llm`/`register_llm_call` on every message; `/`-prefix exits chat
- Corrections → `db.insert_correction(...)` + `srs.ensure_card(right, hint_ru)`
- Tests: parse/format, guard rejections, correction→corrections-table→SRS propagation

### Task 4: Reminders — `english_tutor/scheduler.py`
- `should_send(hhmm_now, reminder_times) -> slot|None` (pure, tested)
- `reminder_loop(bot, conn, config, poll=30s)`: zoneinfo `config.tz`; per active student sends «⏰ Время для английского! …» with due-count; dedup via `reminder_log(student_id, day, slot)` table (survives restarts); `db.reminder_sent`/`mark_reminder_sent`
- `main.py`: start loop as task before polling
- Tests: pure `should_send` (incl. DST-time naive), db dedup helpers

### Task 5: ruff
- dev dependency, `[tool.ruff]` config, fix findings, `uv run ruff check .` clean
