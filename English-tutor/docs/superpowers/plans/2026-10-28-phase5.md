## 1. Phase 5 MVP scope (locked)

1. Telegram UX: reply keyboard (7 learner items + admin keyboard) + contextual inline buttons; slash commands remain.
2. Material mode: text <=6000 chars or voice -> LLM analysis -> phrases/terms/words (5-10 each if present) -> learner selects which to save to SRS -> 3 exercises: pronunciation (voice->Whisper->transcript match), translation RU->EN, dictation (spelling).
3. Interview preset: free-theme lesson topic "собеседование" + terminology vocab; mock interview deferred.
4. Quotas: 5 material analyses/day, SHA-256 cache (no quota on cache hit), 1 LLM call/analysis + Whisper separate, global 200/day preserved, retry accounting.
5. DB: materials, material_items, srs_cards.material_id (nullable), reuse lesson_progress via pseudo-lesson rows.
