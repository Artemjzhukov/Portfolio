---

### Task 1: Review history — `srs_reviews` table
- SCHEMA: `srs_reviews(id, student_id, card_id, day, correct)`; `db.log_review(...)`; written in `review_flow`
- Migration helper `_migrate`: adds `corrections.category` and `lesson_progress.completed_at` columns to existing DBs (ALTER TABLE, idempotent)
- Tests: row written per answer

### Task 2: Stats service — `services/stats.py`
- `overview(conn, tg_id)` → level, lessons_done, spine_done/spine_total (÷6), cards total/due, retention %, corrections count
- `spine_completed_topics(conn, tg_id, level)` — distinct completed curriculum topics
- `error_patterns(conn, tg_id, limit=5)` — frequency of wrong→right pairs
- `categorize_patterns(conn, tg_id, llm)` (async) — LLM classifies uncategorized corrections into fixed EN categories (cached in `corrections.category`), returns EN-key counts; `format_categories(counts)` → Russian «слабые места: …»
- `weekly(conn, tg_id, days=7)` / `format_weekly_lines(conn, days=7)` — counts since window
- Tests: aggregations with seeds, category cache (LLM called once), format outputs

### Task 3: Commands
- Admin `/stats` (all active, one line each) + `/stats <tg_id>` (full detail + patterns + categories + weekly) — admin-guarded, chunked
- Learner `/mylevel` — level, spine progress, due words; reassessment hint at ≥5/6 («переаттестация скоро», mini-test itself → Phase 4)
- Tests: guard, output content

### Task 4: Weekly summary (admin only) — scheduler + config
- `is_weekly_due(now, day, time)` pure; `config.weekly_summary_day/time` (env `WEEKLY_SUMMARY_DAY/TIME`)
- In `reminder_loop`: on due → one aggregated message to admin from `format_weekly_lines`; dedup `reminder_log(slot='weekly-YYYY-Www')`
- `reminder_loop` gains `admin_id` param; `main.py` passes it
- Tests: is_weekly_due, loop sends to admin once (patched clock)

### Task 5: Local run (Docker deferred)
- `run.ps1` (sync + start), README «Работа на своей машине» section

### Task 6: Close-out
- SPEC §12/§14/§15/§21 statuses; full suite; ruff; live smoke checklist
